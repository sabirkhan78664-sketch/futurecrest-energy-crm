# 2408.1 UI update

Based on the supplied dashboard and lead-management reference screenshots.

- Agent dashboard uses compact KPI cards for Today Leads, Today Sales, All Leads, All Sales, Pending Approval, Rejected, Call Backs, and Approval Rate.
- Today Sales and All Sales are green.
- Pending Approval is informational only for Agent.
- Rejected links to rejected records instead of the old Not Sold route.
- Added a compact 7-day activity graph and quick summary.
- My Leads uses compact KPI cards, search/status/fuel/campaign filters, and a lead-management style table.
- My Leads table shows Lead ID, Customer, Mobile, Fuel, Current Retailer, Offered Retailer, Form, and Status.
- Campaign labels show Energy Agent Fill, PHI Fill, or NBN Fill.
- Existing 2408.1 message/group-chat API and UI files were preserved.
